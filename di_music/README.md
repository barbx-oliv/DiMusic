## 2. Introdução 

O projeto **Did it Music** é um aplicativo mobile integrado com uma API do Spotify para ouvir música, além de criar e compartilhar playlist.

O sistema utiliza **Flutter** para a interface de usuário e lógica de controle e **FireBase** como banco de dados relacional. 

### 2.2 Escopo 

O sistema permitirá:
* Cadastro e login de usuário
* Busca de músicas 
* Criação de playlist 
* Dono da playlist pode compartilhar digitando o e-mail do remetente, o tornando colaborador 
*  Dono e colaborador da playlist podem removar e adicionar músicas na playlist 

O sistema utilizará: 
* Flutter 
* FireBase

## 3. Descrição Geral do Sistema 

O sistema deve: 
* Cadastrar e autenticar usuários 
* Permitir crie e compartilhe playlist
* Deverá compartilhar digitando o email do remetente 
* Exibir músicas da playlist 
* Filtrar músicas por gênero, nome e cantor 
* Exibir todas as playlist criadas 
* Dono e colaborador da playlist podem adicionar e remover músicas
